# 국토 공간자료 MCP 서버(maps) - 2026-09-25

요청: "soonkun/mcp_server/maps 폴더에 DEM·토지피복도·토양도를 EPSG:5186(중부원점 TM)으로 표준화해 두고, 시군/도/좌상단·우하단 위경도로 클리핑해 일괄 가져오는 MCP 서버. 자료는 주제별 폴더로 정리. MOPAN에 붙여 테스트."

## MOPAN 연결점

- `frontend/next.config.js` rewrites: `/maps/files/:path*` → `http://127.0.0.1:8200/files/:path*`
- `start_local.sh`: `../../mcp_server/start.sh` 호출(방화벽 다음 줄)
- MCP 서버 등록: 이름 "국토 공간자료(maps)", `http://127.0.0.1:8200/mcp`, 인증 없음, 도구 4개 모두 `read`(자동 사용 가능). `MCP_ALLOW_PRIVATE_NETWORKS=true` 필요(켜져 있음)
- 샌드박스(코드/코워크)는 8200에 못 닿는다 - 필요하면 `scripts/sandbox_firewall.sh`에 포트 추가

## 결과 파일 전달(2026-09-25 저녁, 사용자 지적 "특성정보만 알려줄 게 아니라 파일을 줘야지")

모델이 파일 경로를 코드 글자로만 적어 사용자가 받을 방법이 없었다. 경로를 링크로 쓰라고 프롬프트를 고치는 대신 구조로 해결:
- maps `clip`은 텍스트 블록에 더해 파일마다 MCP 표준 `resource_link` 블록(uri·name·mimeType·size)을 돌려준다. 서버 절대경로(`path`)는 결과 JSON에서 뺐다.
- `app/mcp/client.py` `call_tool` → `ToolResult(text, files)`. uri는 `/`로 시작하는 같은 origin 상대경로나 http(s)만 남긴다(`javascript:`·`//host` 거절, 최대 20개). 테스트 `test_call_tool_keeps_only_safe_resource_links`.
- `run_tool_calls` → Evidence.metadata["files"] → `_citations_from`이 citation에 `files`로 싣는다. 파일을 낸 도구 근거는 모델이 [n]을 안 붙여도 citation에 남긴다(파일이 곧 답).
- 프런트 `MessageBubble`: citation들의 files를 uri로 중복 제거해 답변 밑에 `<a download>` + AttachmentChip. 실측: "전주 수치표고자료 줘" → 칩 1개, `/maps/files/…/dem__전라북도_전주시.tif` 1.0MB, 쿠키 있는 내려받기 200, EPSG:5186 713×647 float32.

## 도구 선택 실패(2026-09-26 아침, "전혀 못하는데?")

실사용 대화: "전주시 수치표고자료가 필요해" → 도구 없이 문서 검색 답변("문서에 값이 없다"), "수치표고자료 줘" → `list_layers`를 불러 레이어 설명만. 원인은 gemma4:26b의 숙고가 (1) 일반 지침 "문서로 답할 수 있으면 도구 없음"에 끌려 '자료 줘'를 문서 질문으로 읽고, (2) 도구 설명이 "목록/자르기"의 기능 서술뿐이라 어떤 말에 어느 도구인지 몰랐던 것.
고친 것:
- maps 도구 설명을 "어떤 말에 이 도구"로 다시 씀: clip = "어느 지역의 DEM·표고·토지피복·토양 자료/파일/지도 줘·잘라줘 → 바로 이 도구(문서 검색 아님), 지역은 앞 대화에서", list_layers/list_regions/describe_region = "…일 때만, 자료 요청은 clip". MOPAN은 설명을 400자까지만 모델에 보이므로 clip 316자. **설명을 바꾸면 MOPAN에서 '도구 발견'을 다시 눌러야 DB 행이 갱신된다**(risk_level은 유지됨).
- `app/mcp/auto.py` `_SYSTEM`에 두 문장: 도구가 만들어 주는 자료·파일·지도 요청은 도구가 필요하다(문서는 설명만 할 뿐 건네주지 못한다), 인자는 앞 턴에서 먼저 채운다('토지피복도도 줘').
재현 결과: "전주시 수치표고자료가 필요해" → clip, 파일 칩 / "토지피복도도 줘" → clip(landcover, 전주시) / 새 대화 "수치표고자료 줘" → "어느 지역의 수치표고(DEM) 자료를 드릴까요?" 되물음. 파일을 받은 직후의 반복 "수치표고자료 줘"는 도구를 다시 부르지 않고 무엇이 필요한지 묻는다(허용 범위).

## 빠진 정보는 되묻기로(2026-09-26, "수치표고 자료가 필요해·전주시 공간정보가 필요해 → 클리핑을 위한 다음 질문으로 넘어가야지")

모델 판단에 맡기지 않고 도구가 구조로 만든다: `clip`은 layer·region이 빠지거나 지역 이름이 여러 곳에 맞으면 실패(isError) 대신 정상 결과 `{"status":"need_input","missing":[…],"question":"…"}`을 돌려준다. isError면 MOPAN이 근거를 버리고 문서 검색으로 새 버리기 때문(실사고). 정상 근거라 RAG를 건너뛰고 답변 모델이 question을 그대로 되묻는다. 스키마에서 `required`를 뺐고 설명에 "모르면 아는 것만 넣어 그냥 부른다"고 적었다.
- `layer: soil` = 토양 8종 일괄. 도 줄임·새 이름(전북·전북특별자치도·경기…) 별칭, `"sigungu": "대구광역시 중구"` 분리.
- 재현(gemma4:26b): "전주시 공간정보가 필요해" → "전라북도 전주시의 어떤 자료가 필요하신가요? …" → "토양도" → 토양 8파일 칩 / "수치표고 자료가 필요해" → "어떤 지역…?" → "전주시" → DEM 파일 / "중구 토지피복도 줘" → 후보 6곳 되물음 → "대구" → 대구광역시 중구 파일 / "전북 완주군 토양 자료 필요해" → 8파일.
- 임시 계정 켜고 끄는 스크립트는 세션 scratchpad에만 두었다(비번은 매번 무작위, 끝나면 비활성).

## 위성영상 - Sentinel-2 + 농림위성 슬롯(2026-09-26)

요청: "일단 sentinel-2부터 붙여. 농림위성(CAS500-4) 데이터도 나중엔 활용할 수 있게 슬롯을 비워놔 - 서버에 넣어두거나 갱신하면서 가져오는 형태."

| 항목 | 결정 |
|---|---|
| 도구 | `fetch_imagery(region, date_from, date_to?, source?, products?, max_cloud?, resolution_m?)` 하나. 정적 레이어의 `clip`과 다른 이유: 시간 축, 전국·전기간 사전 저장 불가 |
| 소스 계약 | `SOURCES` 레지스트리. kind=stac(원격 검색) / kind=local(서버 반입 슬롯 index.json). 장면은 `item{id, datetime, cloud_cover, bbox, assets{red…: href, band, scale, offset, nodata}}`로 정규화 → 합성·산출물 코드는 소스를 모른다 |
| Sentinel-2 | Earth Search STAC `sentinel-2-l2a`(AWS 공개 COG, 인증 없음). 구름 오름차순 최대 100건 검색, 지역과 겹치는 장면만 열어 빈 곳이 없어질 때까지 얹는 first-valid 합성. BOA 오프셋(-0.1) 적용 후 0~1로 자름 |
| 농림위성 CAS500-4 | `data/imagery/cas500_4/` + README + `build.py index-imagery`. 자료를 넣거나 갱신할 때 색인만 다시 돌리면 즉시 `source=cas500-4`로 검색됨. 사이드카 .json(datetime, cloud_cover, bands, scale, offset), 없으면 파일명 YYYYMMDD·5밴드 B,G,R,RE,NIR 가정. 지금은 0장 → "서버에 없습니다 + 넣는 법" 안내 |
| 산출물 | truecolor(visual 자산 RGB 8bit), ndvi(float32, -1~1, 분모 0.01 미만 nodata, 통계+식생 비율), bands(blue,green,red,nir ×10000 uint16) |
| 상한 | 산출물당 6천만 픽셀 - 넘으면 해상도를 2배씩 낮추고 `resolution_note`로 알림(전라북도 → 20m) |
| 빠진 입력 | clip과 같은 `need_input` 질문(지역/기간/소스/산출물). 장면 없음은 `no_data` + 기간·구름 조정 안내 |

실측: 전주시 2025-08 진색+NDVI 10m 2138×1938 18초(NDVI 평균 0.83·식생 85.7%), 완주군 20m 35초, 전라북도 40m 3353×2379 97초·덮임 98%(장면 10). 첫 판은 구름순 6장만 써 도 단위 덮임이 6.6% → 겹치는 장면 전부 사용; 순차 읽기 7분 → 장면 병렬 읽기+밴드 캐시로 97초; 픽셀 상한 6천만 → 1,200만(도는 40m).
MOPAN `.env` `MCP_TIMEOUT_SECONDS=120`(기본 15초로는 위성 호출이 끊긴다). 채팅 재현(gemma4:26b): "전주시 2025년 8월 위성영상 줘" → 진색·NDVI 칩 2개 / "전주시 식생 상태를 위성으로 보고 싶어" → "어느 기간?" → "2025년 8월" → NDVI 통계+칩 / "농림위성으로 완주군 2025년 8월 영상 줘" → "서버에 없음, 넣는 법" 안내.
함정: `rasterio.Env` 옵션은 형을 본다(숫자 int, 스위치 bool - 문자열이면 "an integer is required"); STAC `visual` 자산은 3밴드라 band=[1,2,3]로 읽어야 한다.
