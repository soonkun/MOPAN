### 이번 회차(2026-09-05)에 결정된 것 - 근거는 커밋 메시지와 코드 주석에

- **접기 융합은 "접기만"이다.** 표 합산(cap>=2)·깊이 늘리기(overfetch)·조 단위
  접기는 전부 측정에서 기각 - `app/retrieval/collapse.py` 도크스트링의 표.
- **문서 간 해소의 동일성은 파일명이다.** "특허법 시행규칙.html" -> 특허법시행규칙.
  같은 제목 둘이면 모호로 잇지 않는다. 재적재 경쟁은 SET NULL(0015) + 삽입 전
  dst 검증 + `relink_external`로 막는다. **법령 재적재는 순차로.**
- **분류표 구어체 sparse 확장(Doc2Query)과 흔한 토큰 잘라내기(DF trim)는 기각.**
  둘 다 anchor 무변동 - 기각 사유와 재도전 조건은 `scripts/expand_table_sparse.py`
  도크스트링. 구어체를 움직인 건 전달(`attach_section_heads`)이었다.
- **워크플로우 편집기의 저장 계약은 안 바뀌었다.** 새 UI는 프론트만.
- **실행해보기가 캔버스를 점등한다(소유자 요청).** step 프레임의 (id, state)를
  페이지가 runStates로 들고 EditorCanvas가 테두리를 켠다: running=숨쉬는 링
  (globals.css run-glow - CSS 주석 안에 별표 슬래시를 쓰면 주석이 조기 종료되는
  함정으로 빌드가 한 번 깨졌다), done=켜진 링, failed/timeout=error 링,
  skipped=어둡게("거치지 않은 경로는 켜지지 말고"). 실행이 끝나도 점등은 남아
  경로를 읽을 수 있고, 새 실행·패널 닫기가 지운다. 실측: 분기 거짓 경로 n2만
  opacity-40, 나머지 4개 링.
- **실행해보기의 비활성 조건은 "기능적 변경"만이다(소유자: 자리만 옮겼는데
  못 돌리는 건 부당).** 좌표(x,y)를 뺀 그래프+설정으로 functionalDirty를 따로
  계산해 실행 버튼만 그걸 본다. 저장 버튼·나가기 확인은 여전히 좌표 포함
  dirty - 배치도 저장할 가치가 있다.
- **워크플로우 버전 삭제(소유자 요청).** DELETE /workflows/{id}/versions/{v} -
  활성 버전은 409("먼저 되돌린 뒤")로 거부라 최소 한 버전이 공짜 불변식.
  메시지는 버전 값을 복사해 두므로 기록과 무관. 화면은 비활성 버전 행의
  휴지통 + ConfirmDialog.
- **워크플로우 아이콘은 세로 노드 흐름이다.** 방패(shield-check)는 "왜
  방패인지 모르겠다"는 소유자 지적으로 은퇴 - 사이드바 /workflows와 Composer의
  FLOW가 같은 그림.
- **표 파일(xlsx·csv)이 문서 형식에 들어왔다(app/rag/parsers/excel_parser.py).**
  행을 "컬럼명: 값 | …" 한 줄로 직렬화한다 - 행이 컬럼 이름을 들고 다니므로
  표 조회 MCP가 돌려준 창 안에서 답변 모델이 키 컬럼 추측 없이 값을 읽고,
  RAG 임베딩에도 자연어가 붙는다. csv는 utf-8-sig -> cp949 순서로 시도하고
  둘 다 아니면 뭉개는 대신 ParseFailure(정확일치가 영원히 못 찾게 되므로).
  실전 검증: data.go.kr 농약 정보 10,001행(cp949 CSV -> xlsx 변환) 업로드 ->
  일반 컬렉션(무설정) 색인 19,994청크 -> 채팅이 "사파이어 = 플루디옥소닐
  액상수화제, 살균제, 2000배 희석"을 인용 7건으로 답하고 작물·시기를 되물음.
- **임베딩 429는 오류가 아니라 큰 표를 올린 날의 정상 상태다.** SDK 내부
  재시도(초 단위)는 만행 문서에서 바닥났고(실사고: 첫 색인 failed), embed의
  배치 루프가 RateLimitError에만 지수 백오프(최대 8회, 45초 상한)로 길게
  기다린다 - PIPELINE_TIMEOUT(870초) 안. 429가 아닌 오류는 그대로 실패.
  기존 "429 = 3회" 테스트 계약은 3x8로 갱신.
- **표 조회의 폴백은 마커 일치가 있어도 남는 슬롯을 채운다.** 실사고:
  "사파이어"가 상품분류표 보석 행에 먼저 걸려 방금 임베딩한 등록농약의
  살균제 사파이어가 안 보였다 - 두 세계에 다 있는 말은 흔하다. 본문 쿼리는
  마커 절을 빼서 중복을 막는다.
- **표 파일은 행 묶음 청킹이다(app/rag/chunking/rows.py, worker가 file_type
  xlsx·csv에 자동 적용).** 행 경계 보존·겹침 0·시트 경계에서 절단·초과 행만
  split_to_token_limit. 실측(농약 10,001행 재색인): 19,994청크/4,931,081토큰 →
  **5,001청크/2,837,659토큰(-42.5%)**, 같은 질문이 clarify에서 answer_agent
  직답으로 개선(제형별 정리, 인용 7). 계층 검출(scheme)도 표 파일에선 끈다.
  전부 technical-report.md §9에 수치와 함께 기재.
- **의도 게이트(INTENT_GATE, 기본 켜짐).** 인사말이 RAG를 타던 것을 검색 앞의
  분류 한 번으로 갈라냈다(app/chat/intent.py). 측정: 픽스처 96문항 전부 search,
  대화형 14종 전부 chat, 2회 반복 동일. 실패는 전부 search로 강등.
- **이중 스크롤바의 근본 원인은 sr-only(absolute)였다.** positioned 조상이 없어
  컨테이닝 블록이 뷰포트가 되면서 main의 클리핑을 탈출, 문서를 늘렸다(실측
  /prompts 1448px·/settings 1737px). main과 사이드바 스크롤 영역에 relative -
  전 페이지 docScrollH=900 확인.
- **브랜딩(0016 branding 싱글턴)과 계정 창.** 제목·대문 문구·추천 질문·마스코트가
  관리자 값이 됐고, 테마·로그아웃·닉네임·계정 삭제(비활성화+익명화, 마지막 관리자
  거부)는 사이드바 계정 창으로. 오른쪽 위 테마 순환 버튼(ThemeToggle)은 삭제.
- **MCP는 클로드 데스크톱의 모양이다(소유자 지시).** `+` 메뉴의 서버 단위 토글이
  "기본 사용 설정"(localStorage `mopan.mcp-servers-off`, 기본 켬)이고, 켜져 있으면
  `ChatRequest.auto_tool_ids`로 실려 `app/mcp/auto.py`가 1회 숙고로 알아서 부른다.
  **자동 경로는 read 등급만** - write·destructive는 사람의 결정(@, 승인 게이트)을
  지난다. `@`는 꺼져 있어도 항상 부른다(load_tool_calls, 한 줄도 안 겹침). 낡은
  id는 서버가 조용히 거른다(브라우저 기본 설정이라 섞이는 게 정상). 숙고는
  **의도와 무관하게** 돈다: "오늘 날씨 어때?"는 게이트가 chat으로 분류하지만
  도구가 근거를 내면 search로 승격된다(실사고에서 온 규칙, router.py 주석).
  UI는 `+` 메뉴 > 도구 설정 서브시트(서버가 늘어도 메뉴가 안 자람), 요약 값
  "N/M 켬".
  필수 인자가 질문에 없으면 숙고가 "ask: <되물음>"을 적고 그 문장이 그대로
  답이 된다(prompt_name=tool_clarify, 경고 배너 억제) - "오늘날씨 알려줘"가
  두 번 다 pass로 새던 실사고(trace 실측). 되물음의 답("대전")은 숙고에 실리는
  직전 대화 6턴으로 해석된다. 라이브 왕복 실측 통과. **도구가 근거를 내면 직접
  RAG는 건너뛴다** - "서울 날씨"(search 분류)가 도구 근거 1개에 무관 심사기준
  14개(약 8천 토큰/질문)를 얹어 나가던 실사고. 도구+문서 혼합 질문은 @로.
- **사용자의 "지금"이 프롬프트에 실린다(app/core/localtime.py).** "올해 휴일"이
  2023년으로 답하던 실사고 - 모델의 올해는 학습 시점에 고정된다. 브라우저가
  `client_tz`(Intl 시간대)를 보내고, 서버가 그 시계의 날짜·시각 한 줄을 자동
  도구 숙고와 답변 프롬프트 양쪽에 덧붙인다(닉네임과 같은 주입 규칙). 없거나
  이상한 값은 DEFAULT_TIMEZONE(기본 Asia/Seoul, env)으로 강등.
- **문자 매핑 없는 PDF는 파싱을 거절한다(ParseFailure).** 실사고: 카톡으로
  받은 "TalkFile_NICE 해설서.pdf"가 (cid:NNNN) 쓰레기로 3,221/3,289청크를
  조용히 색인해 검색을 오염시켰다. pdf_parser가 (cid:) 비율 20% 초과면 한국어
  사유("인쇄 > PDF로 저장으로 다시 만들어 올려 주세요")와 함께 거절하고,
  파이프라인은 ParseFailure의 메시지를 error_message에 그대로 싣는다(재시도
  없이 종료 - 같은 파일은 같은 이유로 실패한다). 해당 문서는 재처리로 청크
  0개·failed 전환 완료. 니스 해설서가 필요하면 텍스트 레이어 있는 원본으로
  재업로드.
- **answer_agent v6(라이브 DB 프롬프트): 구체 값은 근거 본문에 있을 때만.**
  실사고 - "소셜네트워크 어플은 제42류[1][8]"라고 답했는데 전달 근거 14개
  청크 원문에 42류·소셜네트워크 언급이 0건이었다(인용이 학습 지식의 장식).
  류·조항 번호·기한·금액은 인용하는 근거 텍스트에 문자 그대로 있을 때만
  적고, 없으면 "이 문서들에는 명시되어 있지 않습니다"라고 말하라는 HARD
  RULE을 v6으로 시딩. 재실측: 같은 2턴 대화에서 9류/38류/42류가 각각 인용
  청크 원문에 실재(유사상품 심사기준). 주의: 검증 프로브는 trace의 snippet이
  아니라 chunk_id 조인으로 원문을 봐야 한다(snippet은 잘려 있다). 코드
  폴백(prompt.py)은 마이그레이션 동등성 테스트가 고정하므로 안 건드렸다 -
  새 배포는 v6을 프롬프트 관리에서 다시 시딩해야 같은 규칙을 갖는다.
- **워크플로우 편집기 2차 개편(소유자 피드백).** 오른쪽 고정 인스펙터를
  없애고 전부 수납: 왼쪽 레일이 워크플로우 설정·도구·노드 순으로 서고, 패널은
  레일 아래에 떠서 열린다(노드/간선을 누르면 자동으로). 흐름은 가로→**세로**
  (포트 위/아래, 세로 베지어, 스타터 그래프 세로 배치 - 기존 저장 그래프의
  좌표는 그대로라 사용자가 끌어 재배치). **실행해보기**: 저장된 그래프를
  채팅과 같은 경로(POST /api/chat + workflow_id)로 돌리고 단계 프레임을
  실시간으로 보여준다 - 전용 dry-run을 만들지 않은 이유는 "여기서 되면
  채팅에서도 된다"는 보장이다. 테스트 대화는 끝나면 지워 기록을 안 더럽힌다.
- **후속 턴은 이력으로 압축해 검색한다(app/chat/condense.py, FOLLOWUP_CONDENSE
  기본 켜짐).** 되묻기의 답("소셜네트워크용이야")이 홀로 게이트에 가면 잡담으로

## 3. 반드시 지킬 규칙

이 프로젝트에서 실제로 사고가 나서 생긴 규칙들입니다. 새 세션에 그대로 전달하십시오.

### 배포

```bash
docker compose build backend worker
docker compose up -d --force-recreate --no-deps backend worker
```

`docker compose up -d --build`는 **이미지만 만들고 컨테이너를 안 바꾼 적이 두 번** 있습니다.
그리고 검증은 작업 트리가 아니라 **실행 중인 컨테이너**에 대고 합니다.

```bash
docker compose exec -T backend grep -c <심볼> /app/app/...
docker compose exec -T postgres psql -U mopan -d mopan -c "select version_num from alembic_version;"
```

`docker compose run --rm migrate`가 **옛 이미지를 조용히 실행한 적**이 있습니다.
마이그레이션은 위 SQL로 직접 확인하십시오.

`docker compose cp`로 **기존 디렉터리에 디렉터리를 복사하면 안으로 중첩됩니다**
(`cp backend/app backend:/app/app` -> `/app/app/app`). 반드시 내용물 복사(`backend/app/.`)로.
실제로 이것 때문에 컨테이너가 옛 코드를 실행하면서 테스트가 헛돌았던 적이 있습니다.

Windows에서 backend 포트(8000)가 `bind: access permissions` 로 거부되면 Hyper-V
예약 범위에 들어간 것 - 관리자에서 `net stop winnat; net start winnat`.

Git Bash에서 컨테이너 내부 경로는 `MSYS_NO_PATHCONV=1`을 붙이지 않으면 뭉개집니다.

### 만들지 말 것

- **인터페이스 뒤에 아무것도 안 하는 껍데기.** `NoneReranker`가 인자를 그대로 돌려주면서
  네 군데 호출부에 꽂혀 있었고, 파이프라인이 몇 주 동안 완성된 것처럼 읽혔습니다.
  "끈다"는 것은 **호출 경로에 없다**는 뜻이지 널 객체를 두라는 뜻이 아닙니다.
- **없는 기능을 있다고 적는 화면·문서·설정.** 설정 화면이 존재하지 않는 재순위 모델을
  "점수를 매기는 대상"이라고 설명하고 있었습니다.
- **도메인 하드코딩.** 모판은 범용 플랫폼입니다. 특허는 예시 데이터입니다.
  청킹 전략 선택이 `[제N류/GNNNNNN]` 표지 개수로 자동 결정되고 있었는데, 다른 사람 문서에는
  아무 소용이 없었습니다. 도메인 지식은 **설정과 프리셋**으로, 코드가 아니라.

### 측정

- **만들기 전에 잰다.** 이 프로젝트에서 상수를 버그에 맞춰 튜닝했다가 결론이 뒤집힌 게
  세 번입니다. 가설이 기각되는 것도 결과입니다.
- **anchor만 보고 고르지 않는다.** 활용률(인용/전달)과 **근거가 실제로 주장을 뒷받침하는지**를
  같이 봅니다. `CANDIDATE_LIMIT` 20에서 모든 숫자 검사를 통과하면서 답을 지어낸 적이 있습니다.
- **인용은 세지 말고 읽는다.** `check_chat.py`가 300자에서 잘라 보여주는 바람에 "근거 없음"
  판정이 틀린 적이 있습니다(지금은 고쳐졌습니다).
- 평가 질문은 **사람이 실제로 칠 문장**이어야 합니다. 맨 키워드 금지.
- `pytest`는 한 번에 하나만. `-n auto` 금지. 자기 `TEST_DATABASE_URL`을 쓰고 끝나면 지웁니다.

### 안전

- `.env`와 API 키는 **읽지도, 출력하지도, 커밋하지도** 않습니다.
- `docker compose config` 금지 — 해석된 환경변수를 키까지 통째로 출력합니다.
- 테스트는 네트워크에 나가지 않습니다. LLM 호출은 provider seam에서 가짜로 대체합니다.
- 색인은 실제 돈이 듭니다. **재색인 전에 비용을 추정해서 말하고**, 끝나면 실제 비용을 보고합니다.
  (참고: 법령 8건 3,335청크 = $0.0102. 유사상품 심사기준 재색인 = 약 $0.03.)
- 문서를 지우기 전에 **id를 먼저 확인**합니다. 정리하다가 진짜 문서를 지운 적이 있습니다.

### 완료의 정의

**커밋 + 푸시 + 배포 + 실행 중인 컨테이너에서 검증**까지 끝나야 완료입니다.
디스크에만 있는 코드는 전달된 것이 아닙니다.

커밋 메시지는 한국어로, 무엇을 바꿨고 무엇을 쟀는지, 그리고 **하지 않은 것**을 `남은 것`
절에 적습니다. `git log`가 그 형식입니다.

## 4. 클론 후 첫 실행

```bash
git clone https://github.com/soonkun/MOPAN.git
cd MOPAN
git checkout management-screens

cp .env.example .env          # OPENAI_API_KEY 등을 채웁니다
```

`data/uploads/`는 저장소에 없습니다. 코퍼스는 다시 올려야 합니다.

`scripts/fetch_statutes.py`의 주석과 `docs/superpowers/specs/`에 적혀 있습니다.

관리자 계정은 첫 가입자가 됩니다(프로덕션 모드에서는 막혀 있습니다 — `auth/service.py:29`).
